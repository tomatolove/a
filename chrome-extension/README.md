# Capture2PDF

FireShot のような、ページ全体をキャプチャして本のPDFに変換する Chrome 拡張機能です。
無料版 FireShot にあるようなキャプチャサイズの上限は設けていません（内部的にはブラウザの
Canvas 高さ上限に達した場合のみ自動でバンド分割していますが、ユーザー操作としては上限を
意識する必要はありません）。

キャプチャ方式は2種類から選べます。

- **スクロールしてキャプチャ**: ページ／領域を自動スクロールしながらタイルキャプチャし、
  1枚の画像に結合してからページ分割します（通常のWebページ・縦スクロール型ビューア向け）
- **ページ送りしてキャプチャ**: 「次のページ」ボタンをクリックしてページを送りながら1ページ
  ずつキャプチャします（クリック式のページめくりビューア向け。結合・分割はせず、1回の撮影が
  そのまま1ページになります）

## 主な機能

- ページ全体を自動スクロールしながらタイルキャプチャし、1枚の画像に結合（スクロールモード）
- 「次のページ」ボタンをクリックしてページを送りながら1ページずつキャプチャ（ページ送り
  モード）。ページ数・クリック後の待機時間は事前設定、トリミングは全ページに一括適用
- ページ自体がスクロールしないSPA型ビューア（後述）にも対応：スクロール領域を自動検出、
  またはクリックで手動選択してキャプチャ可能
- スクロール後の待機時間（ms）を自分で設定可能
- 2枚目以降のタイルで固定ヘッダー/フッター（`position: fixed` / `sticky`）を自動非表示
- キャプチャサイズの人為的な上限なし（内部でCanvas上限を超えたら自動分割して結合）
- 結合画像を編集タブでトリミング（上下左右）
- 好きなページ高さ（px）や用紙サイズプリセット（A4 / Letter / B5）でページ分割（スクロール
  モードのみ。ページ送りモードは1撮影＝1ページなのでページ分割は行いません）
- 不要なページをプレビューから個別に除外
- 本のPDFとして書き出し（ページ画像を個別にJPEG/PNGでダウンロードも可能）
- PDF書き出し時のファイルサイズ削減：同一内容の画像ストリームの重複排除（自動）、埋め込み
  画像の解像度上限の指定（物理ページサイズはそのまま、画素数だけ減らせる）
- PDF内へのOCRテキスト埋め込み（日本語/英語）：目に見えない透明テキスト層として埋め込むため、
  PDFを開くたびに文字を抽出し直す必要がなく、検索・コピーがすぐ使えます
- タイルの境目に線や影が出る場合に備えた「重なり (px)」設定：スクロールを少し重ねて撮影し、
  結合時にその重なり部分の真ん中で継ぎ目を作ることで境目を目立ちにくくする
- キャプチャ実行中は専用のコントロールパネル（別ウィンドウ）が開き、撮影済みタイル/ページを
  その場でグリッド表示で大きくたくさん確認しながら、一時停止・再開・途中終了・キャンセルができる
- 編集画面のプレビューは軽量な縮小サムネイルで表示（書き出しは常にフル解像度）し、トリミング
  変更やタイルの再撮影のたびに全ページを作り直さず済むところは差分更新にしているため、長い本
  でも操作がもたつきにくい

## ページ自体がスクロールしないビューアについて（重要）

EBSCOのeBook/PDFビューアのような一部のSPA製ビューアは、ブラウザのページ全体は固定したまま、
内部の特定の `<div>`（`overflow:auto` な領域）だけがスクロールする作りになっています。この場合
に「全体をキャプチャ（自動検出）」を使うと、ページの `scrollHeight` が変化しないため1枚しか
キャプチャされません。

これに対応するため、拡張機能は以下の順で動作します。

1. まずページ自体が本当にスクロールするか確認します
2. スクロールしない場合、画面に大きく表示されていて実際にスクロールするコンテナを自動検出します
3. 自動検出がうまくいかない場合は、ポップアップの「スクロール範囲を選択してキャプチャ」を使って
   ください。ポップアップが閉じ、ページ上でスクロール領域にカーソルを合わせるとハイライト表示
   されるので、対象をクリックするとそのままキャプチャが始まります（Escでキャンセル）

検出したスクロール領域の外側（固定ツールバーなど）は自動的にトリミングされるため、各ページに
繰り返し写り込むことはありません。

## 長時間・放置キャプチャ（一晩かけてページ数の多い本を読み込む場合）

ページ数が多い本を、寝る前に開始して翌朝確認する、というような放置運用のための仕組みです。

- **撮影済みタイルはそのつど保存**: 撮影が進むごとに1枚ずつディスク（`chrome.storage.local`）
  に保存されるため、途中で何が起きても、それまでに撮影できた分が失われることはありません
- **自動での再開**: Chrome拡張機能のバックグラウンド処理は仕組み上、動作中でも予期せず休止・
  再起動することがあります（長時間の放置では特に起こりやすくなります）。以前はこれが起きると
  撮影がそこで静かに止まってしまい、誰かが気づいて「再開」を押さない限り先に進みませんでした。
  現在は約1分ごとに「撮影中のはずなのに止まっている」キャプチャがないか自動でチェックし、
  見つかったら自動で続きから再開します。何もしなくても、翌朝までにできるだけ多くのページが
  撮影されているようにします
- **キャプチャ元のタブが閉じてしまっても大丈夫**: 以前は撮影中のタブが閉じられると（コン
  ピュータのスリープからの復帰やChromeの自動再起動などで起こり得ます）、それまで撮影した分も
  含めてすべて破棄していました。現在は、少しでも撮影できていればそのまま保持し、後から編集画面
  に進めるようにしています
- **拡張機能アイコンのポップアップに「前回中断したキャプチャ」の案内**: 上記のような理由で
  コントロールパネルのウィンドウ自体が失われてしまっても（ブラウザの再起動など）、翌朝ポップ
  アップを開くと「前回中断したキャプチャが見つかりました（◯◯ページ撮影済み）」という案内が
  表示され、「確認画面を開く」からそのまま続き・編集画面に進めます

それでも、パソコン自体がスリープしたりブラウザが完全に閉じたりすると、その間はもちろん撮影は
進みません。できるだけ完走させたい場合は、パソコンをスリープさせない設定にして、Chromeを閉じ
ないままにしておくことをおすすめします。

## コントロールパネル（進捗確認・一時停止・キャンセル・確認画面）

キャプチャを開始すると、画面右上あたりに小さなウィンドウが自動で開きます（元のポップアップは
すぐ閉じます）。ここでできること：

- 撮影が完了したタイルを1枚ずつサムネイルで確認しながら進捗を見られる
- 「一時停止」でその場で止め、「再開」で続きから再開できる（読み込みが遅い箇所で一旦止めて
  ページの表示を確認してから続ける、といった使い方ができます）
- 「ここまでで終了」を押すと、そこでスクロールを止めて確認フェーズに進む
- 「キャンセル」を押すと、撮影したタイルを破棄してページを元の状態に戻す

ページ最後まで（または「ここまでで終了」で）スクロールし終えると、**自動では編集タブに移動せず**
このパネルが「確認フェーズ」になります。ここで撮影済みタイルを一覧して確認でき、必要なら下記の
「この部分だけ撮り直す」「ここから撮り直す」で修正してから、納得したら「編集画面へ進む」を押す
とその時点で初めて編集タブが開きます。確認せずにすぐ編集画面に進みたい場合も、この「編集画面へ
進む」を押すだけです。

このウィンドウはキャプチャ対象のタブを覆わない位置に開くため、キャプチャ結果には写り込みません。

撮影済みタイルや進行状況はその都度ディスク（`chrome.storage.local`）に保存しており、一時停止中
や確認フェーズの操作（編集画面へ進む前の操作）はすべてそこから読み込んで実行します。Chrome拡張機能の
バックグラウンド処理は一定時間操作がないと休止する仕様がありますが、確認や一時停止をどれだけ長く
続けても、休止・再開によって内部状態が失われることはありません。

## キャプチャ中にエラーが起きたときのリカバリー

タブがクラッシュした・応答しなくなった等でキャプチャ処理自体が失敗した場合は、自動的に3回まで
リトライ（コンテンツスクリプトの再注入を含む）した上で、それでも失敗すればキャプチャを自動的に
一時停止し、パネルに赤いエラー表示を出します。ページを確認し、必要ならパネルの「ページを再読み
込み」でタブをリロードしてから「再開」を押すと、同じスクロール位置から撮り直して続きを進めます。

一方、ページ側がエラー用の画面を表示しただけ（例外は発生していない）場合はこちらでは検知でき
ないため、ライブのサムネイル一覧を見て気づいたら、そのタイルのボタンで対処してください（どちら
も「一時停止中」または「確認フェーズ」のときだけ使えます。キャプチャが進行中のままの場合はまず
「一時停止」を押してください）。

- 「ここから撮り直す」: そのタイルとそれ以降に撮影済みのタイルを破棄し、そのスクロール位置から
  キャプチャをやり直して続きを自動で続行します
- 「この部分だけ撮り直す」: 前後のタイルはそのままに、そのタイル1枚だけをその場で撮り直します
  （キャプチャが全部終わった後の確認フェーズでも使えます）

なお、スクロール領域の画面上の位置はタイルごとに撮影のたびに測り直しています。EBSCOのような
仮想化ビューアでは、この位置が時間の経過でわずかにズレることがあり、ずっと後になって撮り直した
タイルだけ結合画像の中で位置がずれてしまう、ということがないようにするためです。

また、EBSCOのようなページ送り式のビューアは、スクロールが止まると内部でいちばん近い「ページの
区切り」に自動で吸着（スナップ）することがあり、多くの場合 `scroll-behavior: smooth` という
CSSでスクロール自体もアニメーションさせています。これがこちらの操作と時間差で起きると、記録
した位置と実際に写っている内容がズレる原因になります。対策として、

- 撮影中はスクロールのアニメーションを強制的に無効化（瞬時に移動）させています
- スクロール後、位置が変化しなくなる（安定する）まで確認してから撮影します
- 撮影の直後にも位置が変わっていないか確認し、ズレていた場合はそのタイルだけ自動的に撮り直します
  （通常のキャプチャ・「この位置を再撮影」「範囲を選択して再撮影」いずれも対象）

それでもズレが気になる場合は、ポップアップの「重なり (px)」を大きめ（50〜100px程度）に設定
すると、多少の位置ズレがあっても隣り合うタイル同士でカバーし合えるため、結果に出にくくなります。

EBSCOのような仮想化ビューアでは、キャプチャ開始時点ではページ全体の本当の高さがまだ確定して
いないことがあります（スクロールして初めて読み込まれる分があるため）。そのため、スキャンが終わ
りに差し掛かるたびに実際の高さを測り直し、伸びていれば続きも撮影するようにしています。実行の
たびに撮影枚数が変わったり、途中までしか撮れていないのに「完了」と表示されたりする不具合の対策
です。

## 末尾の余白・ブランクページ

編集画面の結合画像・PDFの高さは、キャプチャ開始時に測定した（ときには不正確な）ページ全体の
高さではなく、実際に撮影できたタイルの内容から計算しています。そのため、ページの高さの見積もり
が実際より大きかった場合や、「ここまでで終了」で途中で止めた場合でも、そこから先に空白のページ
が残ることはありません。

## PDFの画質

編集画面の「ページ画像の形式」で PNG を選ぶと、劣化のない可逆画質でPDFに埋め込みます（JPEG圧縮
を一切使いません）。ファイルサイズはかなり大きくなるので、通常はJPEG＋品質スライダーを高めに
した状態で十分です（デフォルトは95）。この形式・品質の選択はPDF書き出し時にのみ使われ、編集
中のプレビュー表示（縮小サムネイル）には影響しないため、画質を上げても編集の動作が重くなること
はありません。

## 結合プレビューでエラー箇所を見つけて撮り直す

編集画面の「結合プレビュー」には、各タイルの境目に薄い点線とタイル番号が表示されます。プレビュー
をスクロールしながら見て、写りがおかしい箇所があればそこをクリックしてください。該当するタイル
の番号・サムネイルがその場にポップアップ表示され、「この位置を再撮影」（範囲を選択して撮影した
セッションでは「範囲を選択して再撮影」も）をポップアップ内からそのまま実行できます。撮り直しが
終わるとポップアップのサムネイルもすぐに更新されます。ポップアップの外側をクリックすると閉じます。

## キャプチャの開始位置を指定する

ポップアップの「現在のスクロール位置から開始する」をオンにすると、常にページ／領域の先頭から
撮影する代わりに、あらかじめ目的の位置までスクロールしてから開始したときの、その位置から撮影を
始められます。表紙や目次を飛ばしたい場合などに使ってください。「スクロール範囲を選択してキャプ
チャ」の場合は、範囲を選択した時点でその領域がスクロールしていた位置が開始位置になります。オフ
（デフォルト）の場合は従来どおり先頭から撮影します。

## キャプチャが全部終わった後に、特定のタイルだけ撮り直す

編集タブの「撮影タイル一覧」に、撮影した各タイルのサムネイルと「この位置を再撮影」ボタンが並ん
でいます。エラーで写りが悪いタイルを見つけたら、そのボタンを押すだけで、そのタイル1枚だけを
元のタブに戻ってピンポイントで撮り直せます（前後のタイルはそのまま）。撮り直しが終わると結合
プレビュー・ページ分割も自動的に再計算されます。

- キャプチャ元のタブが既に閉じられている場合はエラーになるので、確認ダイアログが出たら対象の
  ページを開いているタブをアクティブにしてから「OK」を押してください。現在アクティブなタブを
  使って再試行します
- スクロール範囲を手動選択して撮影したセッションでは、各タイルに「範囲を選択して再撮影」ボタン
  も表示されます。自動検出だと違う領域を拾ってしまう場合はこちらを使い、ページ上で対象領域を
  クリックし直してください

## ページ送り（クリック式）キャプチャモード

スクロールではなく「次のページ」ボタンをクリックして送るタイプのビューア向けのモードです。
ポップアップで「ページ送りしてキャプチャ」を選ぶと、以下の設定が使えます。

- **ページ数**: 1ページ目（今表示している画面）を含む、キャプチャしたい合計ページ数を事前に
  指定します
- **クリックしてから撮影するまでの待機時間 (ms)**: ページ送り後、表示が切り替わるまでの時間
  に合わせて調整してください

「「次のページ」ボタンを選んでキャプチャ開始」を押すと、ブラウザ画面上で実際に「次のページ」
ボタンをクリックして指定するモードになります（クリック位置はここでしか指定しないため、次回
以降も同じ拡張機能・同じタブで押し続けます）。指定した瞬間から1ページ目の撮影が始まり、以降は
自動でクリック→待機→撮影を指定ページ数分繰り返します。

このモードで撮影した各ページは、スクロールモードのように結合してから均等分割することはせず、
1回の撮影がそのまま1ページになります。編集画面のトリミングは全ページに一括で適用されます
（ページごとに個別のトリミングはできません）。

写りが悪いページの撮り直しはスクロールモードと同様にできますが、**場所の指定は人間が行います**。
自動での再ナビゲーションはしないため、対象のページをブラウザで自分で開いてから、編集画面（または
確認フェーズのパネル）の「撮り直す」ボタンを押してください。今そのタブに表示されている画面が
そのままそのページとして撮影されます。

## PDFのファイルサイズ削減とOCRテキスト埋め込み

編集画面の「書き出し」セクションに以下の設定があります。

- **PDF内画像の解像度上限**: 埋め込む画像の画素数に上限をかけます（無制限 / 300 / 220 / 150
  DPI相当）。ページの物理サイズ（PDF上の見た目の大きさ）は変えず、埋め込むピクセルデータの量
  だけを減らすので、通常の閲覧では見た目の劣化はほとんど気になりません
- 内容が完全に同じ画像（同じ形式・同じ解像度・同じバイト列のページ）は、PDF内部で1回だけ埋め込み
  複数ページから共有する（ストリームの重複排除）ことで、無駄なファイルサイズ増加を防ぎます
  （常に自動で行われます）
- **OCRでテキスト埋め込み**: 「日本語」「日本語（縦書き）」「英語」から選ぶと、書き出し時に
  一度だけOCR処理を行い、認識した文字を検索・コピー可能なテキスト層としてPDFに埋め込みます。
  PDFビューア側で開くたびに文字を抽出し直す必要がなくなり、検索・コピーがすぐ使えるようになり
  ます。OCR処理はすべて拡張機能内蔵のエンジンで完結し、外部サーバーには一切送信されません。
  複数ページを同時並行（お使いの環境のCPUコア数に応じて最大4ワーカー）で認識し、認識に使う画像
  も過剰に高解像度にならないよう自動で調整しているため、逐次処理よりかなり速く終わります。それ
  でもページ数が多い本ではある程度時間がかかります。認識精度を優先して、速度優先の軽量版ではな
  くTesseractの標準精度モデルを同梱しています（拡張機能の容量はその分大きめです）。テキストは
  Tesseract自身のPDF出力と同じ仕組み（実体を持たない透明なフォントに実際の文字コードを埋め込む
  方式）で埋め込んでいるため、目に見える文字を装飾する仕組み（旧方式のActualText）とは違い、
  文中の好きな範囲だけをドラッグして選択・コピーできます。日本語（縦書き）は主に縦書きレイアウト
  の書籍向けで、選択範囲の位置精度は横書きほど高くない場合があります

これらはスクロールモード・ページ送りモードどちらのPDF書き出しでも同じように使えます。

## PDFの出力ページサイズ（A4など）を指定する

編集画面の「書き出し」セクションの「出力ページサイズ」で、PDFの各ページを決まった用紙サイズに
そろえられます。

- **自動（画像サイズに合わせる）**（デフォルト）: 従来どおり、撮影・トリミングした画像そのままの
  縦横比でページサイズが決まります
- **A3 / A4 / A5 / A6 / B4 / B5 / B6 / レター / リーガル**: 指定した用紙サイズ（B4/B5/B6は
  日本の書籍でよく使われるJIS規格）にページを統一します。「縦」「横」も選べます。画像は用紙から
  はみ出さないよう縦横比を保ったまま縮小され、余白ができる方向は中央に配置されます（画像自体を
  引き伸ばしたり切り取ったりはしません）。埋め込む画像の解像度（画素数）自体は変わらないため、
  画質には影響しません

この設定はスクロールモード・ページ送りモードどちらでも使え、書き出すPDFの全ページに同じ設定が
適用されます。

## インストール方法（開発者モード）

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、この `chrome-extension` フォルダを選択

## 使い方

1. キャプチャしたいページを開き、拡張機能アイコンをクリック
2. 「スクロール後の待機時間」を必要に応じて調整（読み込みが遅いページは長めに）
3. 画像形式（PNG/JPEG）、固定ヘッダー非表示の有無を設定
4. 「全体をキャプチャ（自動検出）」をクリック。自動でページ最下部までスクロールしながら撮影
   します。1枚しかキャプチャされない場合は、代わりに「スクロール範囲を選択してキャプチャ」を
   クリックし、ページ上でスクロールする領域をクリックしてください
5. コントロールパネルが開き、撮影の様子を確認できます。必要に応じて一時停止・再開・途中終了・
   キャンセルを行ってください
6. 撮影が終わるとパネルが確認フェーズになります。サムネイル一覧でエラーが写っていないか確認し、
   必要なら該当タイルを撮り直してから「編集画面へ進む」を押すと編集タブが開きます
7. 左サイドバーでトリミング範囲とページ分割の高さを設定すると、プレビューは自動的に更新されます
8. 不要なページはページプレビューから「除外する」
9. 「本のPDFとしてダウンロード」または「ページ画像を個別ダウンロード」で書き出し

## 制限事項

- Chrome の内部ページ（`chrome://`, 拡張機能ページなど）はキャプチャできません（Chromeの制約）
- Chrome 標準の PDF ビューアで開いた PDF ファイルはスクリプトを注入できないため、このツール
  でのキャプチャ対象にはできません。Web上の書籍リーダーやHTMLページのキャプチャを想定してい
  ます
- `chrome.tabs.captureVisibleTab` は仕様上おおよそ2回/秒のレート制限があるため、待機時間を
  極端に短くしても実際のキャプチャ間隔はある程度確保されます
- 非常に長いページでは、キャプチャしたタイル画像（データURL）の合計サイズがそれなりに大きく
  なります。`unlimitedStorage` 権限で対応していますが、実行中のタブ・拡張機能のメモリ使用量
  は増加します
